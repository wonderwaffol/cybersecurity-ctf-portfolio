# CTF Disclosure and Sanitization Review

Complete this review for every CTF before its write-up is added to the public portfolio index.

## 1. Event Status and Rules

- [ ] The exact event/challenge has been identified.
- [ ] The event end date has been verified.
- [ ] The event has officially ended, or the organizer explicitly permits write-ups while it is active.
- [ ] Official rules, FAQ, announcement, or organizer guidance about public write-ups has been located.
- [ ] Event-specific embargoes or restrictions have been checked.
- [ ] The verification source and access date are recorded below.

**Official source(s):** [URL or document reference]

**Verified on:** [YYYY-MM-DD]

**Unresolved questions:** [None, or list them]

## 2. Sensitive and Restricted Content

- [ ] Flags and answer strings are removed unless publication is explicitly allowed and useful.
- [ ] Private onion addresses, challenge URLs, IP addresses, hostnames, and infrastructure details are removed or safely generalized.
- [ ] Credentials, passwords, tokens, API keys, cookies, session IDs, authorization headers, and secrets are removed.
- [ ] Personal information and identifiable participant information are removed.
- [ ] Screenshots have been checked visually for browser tabs, bookmarks, account names, notifications, paths, metadata, and hidden secrets.
- [ ] Commands and outputs have been sanitized without changing their technical meaning.

## 3. Copyright and Redistribution

- [ ] Challenge files are linked to only when organizers provide an official public source.
- [ ] Original binaries, datasets, source archives, documents, and media are not redistributed without permission.
- [ ] Only limited excerpts or transformed evidence needed to explain the analysis are included.
- [ ] Organizer branding and challenge text are used appropriately and not presented as my own work.

## 4. Accuracy and Evidence

- [ ] Every listed tool was actually used.
- [ ] Every listed technique is supported by notes, commands, screenshots, files, or reliable recollection.
- [ ] Guided steps and independent discoveries are clearly distinguished.
- [ ] Discovery method, underlying vulnerability, exploitation technique, and impact are not conflated.
- [ ] Unknown dates, scores, rankings, commands, or details are labelled unknown or omitted.
- [ ] Claims and terminology have received a final technical review.
